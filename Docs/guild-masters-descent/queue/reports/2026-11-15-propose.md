# Proposal: next build batch toward the Unity MVP

> **Status:** Mastermind proposal of 2026-11-15, from `forge-queue-planner` against the Goal,
> measured from the game's main branch (38a407c). Rows queued under the user's standing yes.

Four gaps remain. The rules engine and the main loop (guild hall, recruiting, Dorms, shop,
missions, a 10-floor dive, saving) are built. What's missing is two things about specials on the
battle screen, two lists the Goal asks for that the game never produces, and one rule the docs
don't give.

## Proposed

PROPOSAL: Battle: show the three lasting effects while they run (the Rogue vanished, Shields Up on the Tank and the allies behind it, the Mage's field over two enemy columns) as labelled bright-yellow shapes until annie makes art, and add each one to the missing-art list [look] [M] — the engine runs all three, but the battle screen never reads their state (no view code mentions Vanish, Shields Up or the field). So a Rogue that can't be hit, or field damage appearing from nowhere, can't be seen, and the Goal needs specials to matter.
PROPOSAL: Battle: let any fighter use their special, not just the first four in party order. Keep annie's approved four skill buttons, and have the fourth follow whichever party fighter the player last tapped [look] [S] — `BattleScreen` has `SkillSlots = 4` and `.Take(SkillSlots)`, so in a party of up to 15 the fifth fighter onward can never fire one. The original Combat doc gives every member that use. Following the last tapped fighter is the one option that keeps the approved layout, and it reuses the selection `ArmButton` already tracks.
PROPOSAL: decide: what happens when the guild has no living members, too little gold to hire one, and nothing left to sell [research] [S] — death is permanent, the guild can't go into debt, and missions need members, so that save is stuck for good. The cheapest hire is 80 gold and a new guild starts with 500. No doc gives a way back, and it's a rule, not a number.
PROPOSAL: Placeholder and missing-art lists: write every tuning placeholder (name, value, note) and every missing-art name to a file the user and annie can read [look] [S] — the Goal says both get "listed". `Tuning.ListPlaceholders()` and `MissingAssets.All()` exist, but only tests call them, and the missing list only fills at runtime, so neither list has ever reached anyone.
